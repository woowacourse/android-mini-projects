## B. 개발 진행 상황

### 이번 주에 만든 핵심 기능

1. UI
2. 출발지와 도착지를 선택 / 경로 탐색 및 안내

### 진도

| 1주차 MVP 범위     | 현재 상태 |
|----------------|-------|
| 목적지까지 최적 경로 탐색 | 완료    |
| 가상 맵 만들기       | 완료    |
| 고대비 UI         | 완료    |
| 음성 안내 메세지 출력   | 진행 중  |
| 출발지/목적지 선택     | 완료    |

### 발표에서 보여줄 수 있는 핵심 흐름

- 사용자가 현재 위치와 목적지를 선택한다
- 안내를 시작한다
- 안내 메시지를 출력한다
- 지도에서 남은 거리와 점형 블록 정보를 알 수 있다
- 음성 버튼을 통해 음성 가이드를 다시 들을 수 있다
- 다음 점형 블록에 도착하면 다음 길로 안내를 할 수 있다

### 범위 변경 (있다면)

- 늘어난 것: X
- 줄어든 것: 테스트 장소 판교역 -> 우아한테크코스 11층 교육장
- 이유: 판교역은 테스트 하기 힘들고 단기간에 MVP를 테스트 하기 힘들다고 생각해 변경하게 되었습니다
