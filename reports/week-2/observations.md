## 답변 & 인사이트

| 답변                                                                             | 인사이트                                                              |
|--------------------------------------------------------------------------------|-------------------------------------------------------------------|
| 중증 시각장애인일수록 버스를 기피하고 지하철을 훨씬 선호함. 버스는 독립적으로 타기에 한계가 있음                         | 지하철이 시각장애인에게 핵심적인 대중교통 수단 -> 지하철 중심 서비스 설계가 타당함                   |
| 강남역처럼 넓은 역에서는 길을 잃기 쉬움. 카메라로 출구 번호를 확대해서 보거나, 출구 번호의 규칙성(시계 방향 배치)을 외워서 대응함    | 출구 번호에는 시계 방향 규칙이 있음(1번 건너편에 마지막 번호)                              |
| 자주 가는 역은 동선을 외워서 다님. "이수역 7호선 -> 4호선은 뒤쪽 탑승, 노원은 앞쪽 탑승" 등을 기억함. 낯선 곳에서는 헤맴     | 시각장애인은 기억에 크게 의존 -> 새로운 역에 대한 사전 정보 제공이 핵심 니즈                     |
| 남부터미널에서 개찰구를 못 찾아 지하 상가를 따라 한 정거장을 걸어감. 을지로, 잠실 등 복잡한 지하 공간에서도 유사한 경험          | 지하철역과 상가가 연결된 복합 공간이 헷갈리기 쉬움.                                     |
| 여러 역을 한 명의 역장이 관리. 공익근무요원도 감소. 도움을 요청할 사람이 현장에 없는 경우 많음                        | 인적 지원에 의존하기 어려운 현실 -> 기술적 보조 수단의 필요성 증가                           |
| 벽쪽 탐색, 청소 냄새 활용, 점자 표지판(남녀 구분) 활용. 화장실이 숨어있는 역에서는 한 바퀴 돌기도 함.                  | 화장실 위치 안내는 필요함. 역별 화장실 위치 데이터를 앱에 포함하면 유용                         |
| 보행 훈련에 엘리베이터 경로가 포함되지 않으면 아예 이용하지 않음                                           | 훈련된 동선 밖의 시설은 존재해도 활용되지 못함 -> 엘리베이터 위치 및 경로 안내 필요                 |
| 지팡이는 즉각적 물리적 장애물 감지. 앱이 5m 앞 정보를 알려줘도 발밑 함정은 감지 불가 -> 한 번 사고 나면 신뢰 상실          | 앱은 지팡이를 대체하는 것이 아니라 보조하는 도구여야 함. 지팡이가 못하는 것(출구 번호, 방향 정보)을 제공해야 함 |
| 점자 블록과 안내견은 목적지를 안내하는 것이 아니라 장애물 없이 안전하게 이동하게 해주는 역할                           | 안내견 & 점자 블록 != 목적지 안내. (안전 보행은 지팡이/안내견 영역)                        |
| 빵집 냄새, 음악 소리, 생선 가게 냄새 등을 랜드마크로 활용.                                            | 앱이 음성 안내를 할 때 청각을 과도하게 점유하면 안 됨 -> 간결하고 명확한 안내                    |
| 저시력인은 다크모드 선호. 색상은 고대비이되 일률적이어야 함(메뉴끼리 같은 색). 다양한 색을 섞으면 오히려 어지러움. 볼드체는 호불호 있음 | 고대비 + 일률적 색상 + 2~3색 이내 + 큰 글씨. 발달장애인용과 시각장애인용 UI는 접근 방식이 다름       |
